# Метод диагностики тепловых карт на основе разложения по динамическим модам
Выпускная квалификационная работа бакалавра

Цель проекта заключается в локализации и характеризации источников, в виде извлечения параметров частоты, фазы и амплитуды из последовательности измерений динамической системы.
Для решения задачи используется оптимизрованное разложение по динамическим модам и разработан метод извлечения параметров тепловых источников из динамических мод и их динамик.

# Инструкция по запуску
Для запуска рекомендуется использовать пакетный менеджер uv.

1. Установка зависимостей
`uv pip intall -r requirements.txt`
2. Решение уравнения из конфигурации
`uv run src/solver.py test_1`
3. Разложение по динамическим модам
`uv run src/heatdmd.py test_1`
4. Диагностика полученных данных
`uv run src/tester.py test_1`

Либо запустить сразу все этапы:
`uv run src/main.py test_1`

## Формат конфигурации
- `Name`: имя конфигурации
- `Lx`: длина области по оси x
- `Ly`: длина области по оси y
- `Nx:` число пикселей по оси x
- `Ny`: число пикселей по оси y
- `a`: коэффицент теплопроводности
- `T`: время измерения в сек.
- `dt`: частота дискретизации в сек.
- `u_top`: граничное условие на верхней границе
- `u_bottom`: граничное условие на нижней границе
- `u_left`: граничное условие на левой границе
- `u_right`: граничное условие на право границе
- `mean`: среднее гауссова шума
- `variance`: дисперсия гауссова шума
- `method`: численный метод решения уравнения теплопроводности
- `sources:`: список тепловых источников
    - `<source_name>:`: название источника
        - `amp`: амплитуда источника
        - `x0`: координата x центра источника
        - `y0`: координата y центра источника
        - `width`: ширина источника
        - `omega`: частота источника в рад./с
        - `phi`: фаза источника в радианах
- `save_interval`: частота сохранения снимков
- `modes`: число мод для разложения
- `hankel`: глубина временной задержки предобработки Ганкеля
